Petunjuk Streaming FFmpeg & HTTP Server

Pastikan web server aktif dan FFmpeg memproduksi file HLS segment ke dalam folder yang sesuai:

1. Jalankan Semua (Web + Cam 1 + Cam 2) dengan Docker Compose:
docker compose up -d
2. FFmpeg Kamera 1 - Depan (192.168.123.107):
ffmpeg -rtsp_transport tcp -rtsp_flags prefer_tcp -i "rtsp://admin:password@192.168.123.107:554/Streaming/Channels/102" -map 0:v:0 -an -c:v libx264 -preset ultrafast -tune zerolatency -b:v 1000k -f hls -hls_time 2 -hls_list_size 5 -hls_delete_threshold 1 -hls_flags delete_segments+append_list+independent_segments+omit_endlist -hls_segment_filename camera-1/segment_%05d.ts camera-1/index.m3u8
3. FFmpeg Kamera 2 - Belakang (192.168.123.106):
ffmpeg -rtsp_transport tcp -rtsp_flags prefer_tcp -i "rtsp://admin:password@192.168.123.106:554/Streaming/Channels/102" -map 0:v:0 -an -c:v libx264 -preset ultrafast -tune zerolatency -b:v 1000k -f hls -hls_time 2 -hls_list_size 5 -hls_delete_threshold 1 -hls_flags delete_segments+append_list+independent_segments+omit_endlist -hls_segment_filename camera-2/segment_%05d.ts camera-2/index.m3u8
